# TemPad

아기의 온도 흐름을 한눈에 확인하는 모니터링 MVP입니다. iPhone 앱과 브라우저에서 실행하는 웹 버전을 함께 제공합니다.

## 웹에서 열기

[TemPad 실행하기 — GPT Sites](https://tempad-monitor.guro1000.chatgpt.site)

누구나 링크로 접속할 수 있습니다. 브라우저에서 실행되는 웹 버전이며, iPhone 설치 파일 배포 링크는 아닙니다.

## 주요 기능

- 원본 아기 형태를 유지하는 호흡·팔·고개·수면 자세 움직임
- 52 × 30 격자와 지점별 온도 선택, 빈 곳을 눌러 기본 머리·몸통 추적으로 복귀
- 초록색 추적 상태 표시와 온도에 따른 색상 변화
- 온도 상승 및 설정 범위 이탈 알림, 알림 기록, 온도 기준 설정

웹에서는 현재 온도 오른쪽에 **최근 6시간 미니 그래프**를 표시하고, 아기 모니터링 화면 아래의 상세 그래프는 **1시간·12시간·하루·일주일**로 전환할 수 있습니다. 미니 그래프는 현재 숫자와 같은 대표 온도 또는 선택 지점을 보여줍니다. 격자를 선택하면 해당 지점의 온도를 표시하고 **2초 뒤 기본 추적으로 돌아옵니다**. 새 지점을 선택하면 2초를 다시 셉니다. 상세 그래프에서는 머리·몸통을 선택하거나 격자에서 고른 지점의 흐름을 살펴봅니다. 선택 기간의 **최고 온도는 빨간 수평선, 최저 온도는 초록 수평선**으로 표시합니다. 미니 그래프와 하루 기록은 미측정 구간에서 선을 끊고, 일주일은 날짜별 평균을 선으로 연결합니다.

웹에서는 모니터링 제목 옆에 현재 상태의 얼굴 아이콘만 표시하고, 아기 이미지 아래에 자세 안내 문구를 둡니다. 빨강·주황·노랑·초록·파랑으로 알림 상태를 구분하며, 온도 변화가 발생하면 화면 위에서 내려오는 알림을 보여줍니다. iPhone 원본은 별도의 실시간 상세 화면과 기간별 기록 화면을 사용합니다.

웹 상단에서 **모드 1 · 평시**와 **모드 2 · 열날 때**를 선택합니다. 평시 모드는 36.8°C 주변의 안정적인 온도를 5초마다 갱신합니다. 열날 때 모드를 선택하면 몸통 36.8°C와 머리 36.6°C부터 다시 시작하고 1초마다 갱신합니다. 기본 설정 기준 **4초에 37.3°C 상승 알림**, **10초에 38.1°C 상한 초과 알림**, 약 16초에 최고 38.6°C를 표시합니다. 앞선 팝업이 열려 있으면 확인한 뒤 다음 알림을 볼 수 있습니다. iPhone 원본은 기존 속도로 실행 시 온도 상승 흐름을 시작합니다.

웹 기록에는 최근 7일의 입력과 수유·안기 등 미접촉 구간을 구성했습니다. 패드에 접촉하지 않은 구간은 온도를 0으로 대체하거나 앞뒤를 이어 그리지 않으며, 평균·최저·최고 계산에서 제외합니다. 미측정 구간을 누르면 ‘측정 없음’으로 표시합니다. 현재 두 모드의 실시간 입력은 패드 위에 있는 상태이며, 실제 패드의 접촉 감지는 아직 연결하지 않았습니다.

## iPhone 앱 실행

1. Mac에서 `TemPad.xcodeproj`를 Xcode로 엽니다.
2. iPhone 시뮬레이터를 선택하고 Run을 실행합니다.
3. 실제 iPhone에 설치할 때는 본인의 개발 팀과 서명을 설정합니다.

최소 iOS 17, Swift 5.9. 외부 Swift 패키지나 서버 없이 실행됩니다. `Core`는 앱과 분리된 로컬 Swift 패키지입니다. `project.yml`을 바꾼 경우 XcodeGen으로 프로젝트를 다시 생성할 수 있습니다.

## 웹 버전 실행

저장소 루트에서 다음 명령을 실행한 뒤 `http://localhost:8080`을 엽니다.

```sh
python3 -m http.server 8080 --directory Web/dist
```

웹 버전은 빌드 과정이나 외부 JavaScript 패키지 없이 동작합니다. WebGL로 아기 이미지와 격자를 함께 변형하고, WebGL을 사용할 수 없는 경우 Canvas로 표시합니다. 새로고침하면 평시 모드로 시작하며, 열날 때 모드로 바꾸면 온도 상승 흐름이 처음부터 시작합니다.

## 소스 구성

| 경로 | 내용 |
|---|---|
| `App/` | SwiftUI 화면, SpriteKit 온도 투영, 상태 관리 |
| `Core/` | 온도 입력, 알림 판단, 몸 움직임, 격자 좌표 |
| `Tests/` | iPhone UI 검사 코드 |
| `Web/dist/` | 배포 가능한 웹 앱과 이미지 |
| `ASSETS.md` | 제공된 로고·아기 이미지 적용 내역 |

코어 검사는 `swift test --package-path Core`, iPhone UI 검사는 Xcode의 Product → Test로 실행할 수 있습니다.

## 구현 범위

TemPad의 제품 전제는 온도·압력 센서가 있는 접촉 패드와 자세·의복·접촉 조건을 고려하는 보정 소프트웨어입니다. 화면의 색상 투영은 열화상 카메라 영상이 아닙니다.

이 저장소의 온도·자세 입력은 화면과 알림 흐름을 검토하기 위한 앱 내부 입력입니다. 실제 패드 통신, 센서 기반 자세 분류, 의복 판단과 임상적으로 검증된 온도 보정, 원격 서버·APNs는 연결하지 않았습니다. 기본 영역과 0.5°C 상승 규칙은 MVP 동작 기준이며 질병 진단이나 위험 확률을 판정하지 않습니다. 초록색 표시등은 추적 상태를 뜻합니다.

웹에서는 페이지 상단의 알림을 제공합니다. 페이지가 닫힌 상태의 상시 모니터링이나 원격 알림은 제공하지 않습니다. 온도 기준 설정은 사용하는 브라우저에 저장됩니다.

## 확인한 동작

iPhone 시뮬레이터 빌드·실행, 정상 온도 시작과 상승/상한 팝업, 재실행 초기화를 확인했습니다. 웹은 390px 모바일 화면에서 격자 선택·기본 추적 복귀, 확대 모니터링, 하루/일주일 기록과 두 단계 팝업을 확인했고 GPT Sites에 공개 배포했습니다. 검증 범위는 빌드와 화면 동작 확인이며, 전체 자동 검사는 실행하지 않았습니다.

추가로 웹 모드 전환 후 정상 온도로 초기화되는 동작, 열날 때 모드의 두 단계 팝업, 하루 미측정 구간 선택, 일주일 7개 날짜의 평균 선을 확인했습니다.
